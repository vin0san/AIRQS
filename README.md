# AIR QUALITY MONITORING SYSTEM

This project measures environmental pollutants like CO2, PM2.5, and other key air quality parameters using an Arduino Uno R3. It provides real-time readings that can be displayed or logged for further analysis. The goal is to keep it simple, functional, and easy to replicate.

# Features
Measures key pollutants (CO2, PM2.5, etc.)

Real-time data collection and monitoring

# Components

DHT11: temperature and humidity sensor

MQ135: gas sensor for detecting various gases.

Microcontroller(Arduino uno R3): The main controller for data processing and communication.

Display module(OLED): for displaying sensor readings.

Jumper wires: For connections.

Power Supply – USB or external, as needed.
